# Knuut AI Improvement Roadmap
Based on Evaluation Feedback

## 🎯 Priority 1: High Impact, Quick Wins

### 1. User-Stage Onboarding
**Status:** 🔴 Not Started
**Impact:** High - Tailors experience immediately
**Effort:** Medium
**Implementation:**
- Add onboarding flow on first visit
- Ask: "When did you arrive in Finland?"
  - Just arrived (0-6 months)
  - Been here (6+ months, seeking work)
  - Long-time resident (2+ years)
- Customize dashboard based on selection
- Store in user profile

### 2. City-Specific Checklists
**Status:** 🔴 Not Started
**Impact:** High - More relevant for users
**Effort:** Medium
**Implementation:**
- Add city selector (default: Kajaani)
- Customize "Start Here" with local offices
- Add map of local DVV/Kela offices
- Show wait times if available

### 3. Interactive Cultural Quizzes
**Status:** 🔴 Not Started
**Impact:** Medium-High - Reinforces learning
**Effort:** Low-Medium
**Implementation:**
- Add "What would you do?" scenarios after each culture card
- Simple multiple choice
- Immediate feedback
- XP rewards for correct answers

### 4. Enhanced Visual Progress Indicators
**Status:** ✅ Partially Done (Visual answers added)
**Impact:** High - Already implemented
**Effort:** Done
**Next Steps:**
- Add more granular progress tracking
- Show streaks and consistency
